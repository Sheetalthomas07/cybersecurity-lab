# Cybersecurity Labs

Hands-on cybersecurity labs focused on web application vulnerabilities, security testing, and mitigation techniques.

## Labs

### SQL Injection
A Flask-based application demonstrating secure database interaction using parameterized SQL queries.

**Topics:**
- SQL Injection
- SQLite
- Flask
- Parameterized Queries
- Secure Coding

### Log Injection
A Flask-based logging application demonstrating protection against log manipulation through CR/LF characters.

**Topics:**
- Log Injection
- Input Validation
- CR/LF Handling
- Secure Logging

### CRLF Injection
A Flask-based application demonstrating mitigation of CRLF characters in user-controlled input.

**Topics:**
- CRLF Injection
- HTTP Response Manipulation
- Input Validation
- Web Application Security

## Disclaimer

These labs are created for educational purposes and are intended to be run in controlled, local environments.
